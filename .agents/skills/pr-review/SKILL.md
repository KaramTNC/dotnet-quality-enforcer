# Pull-request review

1. Establish the diff and correct comparison base.
2. Read applicable agent guidance, architecture contracts, and workflow checks.
3. Prioritize actionable correctness, security, concurrency, performance, and
   test-gap findings over style preferences.
4. Trace relevant control flow far enough to support each finding with evidence.
5. Report severity, impact, file references, and concrete remediation.
6. Do not edit during review unless explicitly asked to fix findings.
